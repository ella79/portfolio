create-agentic-playwright-project

A free, open-source scaffolder for a Playwright and TypeScript QA project with the architecture already defined: Page Object Model, fixtures, e2e / visual / API, an evals gate, sharded CI and Docker. The Claude Code agents (planner, manager, generator, healer, reviewer, reporter) and skills come already wired into the workflow. One command, and you start from a real structure instead of a blank page.

Just shipped

linkedin-content-skills

Sixteen free, open-source Claude Code skills for writing LinkedIn content in your own voice: posts, carousels, comments, replies, outreach, a weekly plan and a post-mortem audit, coordinated by a router that checks each skill’s preconditions and refuses to call it done before the gates pass. Five Python scripts do the checking: one scores how human a draft reads, one checks what the feed actually penalises, one refuses any number that is not in your research. The audit writes what worked back to a file the writing skills read, so your own numbers outrank generic advice. Voice-agnostic, grounded, drafts only, nothing posts on its own.
