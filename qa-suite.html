Agentic Playwright suite

Playwright and TypeScript, agents over Playwright MCP, a containerised pipeline

Every run of this suite in GitHub Actions publishes its results as an Allure report. This page reads that report: the suites and the areas on the left are the ones that ran, and the runner replays them test by test, with the statuses and the durations the run recorded. A browser cannot start Playwright itself, so what you watch here is that published run rather than a new one, and the report it came from is embedded at the bottom of the page.

That makes this page a consumer of another repository's build output, across two pipelines with no build step between them, so the dependency is written down rather than assumed. A contract states which documents this page reads and which fields inside them. A scheduled job here checks the published report against it, and the same check runs from the other side, on a freshly generated report, so that a change which would break this page fails the run that made it rather than being discovered here.
